# Logos de transportistas

El briefing de TrackFlow menciona UPS, FedEx, DHL, MRW y SEUR dentro de
su red de ocho proveedores. Se presentan como transportistas, sin atribuir
testimonios, certificaciones, resultados ni una relación de cliente.

Activos descargados de sus sitios oficiales el 10 de octubre de 2026:

- UPS: https://about.ups.com/content/dam/upsstories/images/logo/ups-logo-wo-text.svg
- FedEx: https://www.fedex.com/content/dam/fedex-com/logos/logo.png
- DHL: https://www.dhl.com/content/dam/dhl/global/core/images/logos/dhl-logo.svg
- MRW: https://www.mrw.es/img/logo.png
- SEUR: https://www.seur.com/images/logo.png

Los originales se sirven localmente, conservando sus proporciones.
CSS los presenta en monocromo. MRW usa una matriz SVG para separar
las letras de su fondo azul; SEUR utiliza inversión y mezcla `screen`
para integrar el fondo claro sobre negro. Las marcas pertenecen a sus
respectivos titulares.

La franja utiliza dos copias visuales idénticas y una traslación lineal
de 62 segundos, sin salto al reiniciarse. Se detiene fuera de pantalla
o con la pestaña oculta. No lleva botón de pausa por petición del usuario.
Con movimiento reducido, muestra una sola copia estática que se distribuye
en varias filas en móvil. Un texto accesible enumera los cinco nombres;
las copias decorativas no se anuncian a lectores de pantalla.
